## MapData Compatibility Files



This folder contains the shared mapdata files used across our maps.



Its purpose is to ensure that all compatible maps can work together properly without requiring customers to manually create compatibility files.





###### **Included in this folder**



* Shared files used by multiple maps



* Compatibility-related mapdata



* Files required for proper integration between supported products





###### **Why this is important**



When using several maps together, some shared files are necessary to prevent issues and make sure everything loads correctly.



This system allows our maps to be combined more easily and helps keep installation simple and clean.





###### **Installation**



To ensure proper compatibility between maps, these files must only exist inside the MapData resource.





If you are installing this MapData resource, you must:



* Open the other map resources



* Locate any files that are also present in the MapData resource



* Remove those files from the individual map resources



* Keep them only inside the MapData resource





This ensures that all maps use the same shared files, preventing conflicts and compatibility Issues.







**Please note**



* Do not keep duplicate versions of these files inside multiple resources.
* These files are intended to be shared across multiple maps



* They are provided to remove the need for manual compatibility setup



* Future maps may also rely on this folder for full compatibility
